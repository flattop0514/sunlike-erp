# 假别代号查询与说明 (`sz`)

本文档介绍假别代号（`SZ_BASE`）接口的使用方法及各假别的属性规则。

---

## 1. 基础命令速查

- **查询全部假别代号**：
  ```bash
  ./erp_cli sz list
  # 可选分页参数: -rows <每页笔数> -page <页码>
  ```
- **查询单个假别代号**：
  ```bash
  ./erp_cli sz get -no C01
  ```

---

## 2. 假别代号使用原则（必读）

- **⚠️ 绝不硬编码假别代号**：不同企业或账套的假别代号可能存在增删或调整。在生成请假单（`leave`）、外出单（`goout`）或打卡补卡（`card`）前，**一律先通过 `./erp_cli sz list` 实时获取当前账套的假别列表**。
- **计量单位（`UT_DAY`）含义**：
  - `3` = **天**（如特休/年假、公假、丧假、婚假、产假）
  - `5` = **小时**（如事假、病假、旷职）
  - `4` / `1` = **次**（如迟到、早退、未打卡、忘打卡）
- **常见假别示例**：
  - `C01`: 迟到
  - `C02`: 早退
  - `C03`: 事假
  - `C04`: 病假
  - `C05`: 旷职
  - `C06`: 特休（对应大陆“年假”）
  - `C07`: 公假
  - `C08`: 丧假
  - `C09`: 婚假
  - `C10`: 产假
  - `C11`: 忘打卡
  - `C12`: 未打卡
  - `C13`: 生理假
  - `C14`: 补休
